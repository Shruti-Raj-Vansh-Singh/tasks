# Baseline Repo Layout

The clean baseline Jinja repository (upstream 3.1.6) plus this task's
scaffolding is placed under:

`repo/src/`

Run commands in this task assume `repo/src/` is the repository root. The task
brief lives at `repo/src/TASK.md`, the code to complete is
`repo/src/notifier/render.py`, and its tests are under
`repo/src/notifier_tests/`.
